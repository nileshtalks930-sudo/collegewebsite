# Northmere College Website

A full multi-page marketing site for **Northmere College**, a fictional liberal arts college.

## Pages

- **Home** — full-bleed campus hero, academics & campus teasers, admissions CTA
- **About** — mission, history timeline, leadership
- **Academics** — program areas and research highlights
- **Admissions** — how to apply, deadlines, CTAs
- **Campus Life** — housing, clubs, athletics, arts
- **Contact** — details + inquiry form

## Stack

- React 19 + Vite
- React Router
- Custom CSS design system (Fraunces + Outfit)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
