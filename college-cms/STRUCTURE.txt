Feature → folder map
--------------------
 1. Secure Login ............ app/Views/admin/auth, Middleware, Core/Auth
 2. Role Based Admin ........ users/, Middleware/Role
 3. Menu Management ......... menus/
 4. Submenu Management ...... menus/ (nested)
 5. Dynamic Pages ........... pages/
 6. HTML Page Editor ........ pages/ (+ editor assets)
 7. File Upload Manager ..... media/, public/uploads/
 8. Department Module ....... departments/
 9. IQAC Module ............. iqac/
10. NAAC Module ............. naac/
11. Notice Module ........... notices/
12. Gallery Module .......... gallery/
13. Download Module ......... downloads/
14. Homepage Slider ......... slider/
15. Site Settings ........... settings/ (+ 009_settings.sql)
    Database Config ......... settings/database (writes config/database.php)
16. SEO Settings ............ seo/
17. Backup Database ......... backup/, database/backups/

Build order (incremental — do not implement all at once)
--------------------------------------------------------
  Step A: Core (PDO Database, Router, base Controller/Model, Session)
  Step B: Config + database schema skeleton
  Step C: Secure Login + Role middleware
  Step D: Admin layout (AdminLTE) + Dashboard
  Step E: Modules one-by-one (Menu → Pages → … → Backup)
